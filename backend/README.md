# SHAKA Backend

This folder is reserved for the backend service (API, database integration, authentication, etc.).

## Getting Started

Depending on the backend technology of your choice (Node.js/Express, Python/FastAPI, Go, etc.):

1. Initialize your project inside this folder:
   - **Node.js**: `npm init -y`
   - **Python**: `python -m venv venv`
2. Configure environment variables (e.g., `.env`)
3. Connect your API endpoints with the frontend located in `../frontend`
